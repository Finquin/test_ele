## 11ty — Fechas en blog posts y `eleventyComputed` (Resumen Ultra Compacto, fiel al texto)


## 📦 Cambio de layout aplicado

```js
module.exports = {
  layout: "layouts/post.xhtml",
  tags: ["post"],
  author: "Bryan Robinson",
}
```

📌 Impacto:

* Se aplica a todos los archivos dentro de `posts/`.
* Centraliza configuración.
* Reduce repetición.


# 📅 Problema con fechas en 11ty

### 🔎 Comportamiento por defecto

11ty crea automáticamente:

```
page.date
```

❌ Problema:

* Se genera al momento del **build**.
* No refleja la fecha real de publicación.
* Puede variar según entorno/host.


## ✅ Formas válidas de definir fecha

### 1️⃣ En el nombre del archivo

```
2022-01-01-my-post.md
```

* URL final → `my-post`
* Fecha → 1 de enero de 2022
* Método común en Jekyll


### 2️⃣ En frontmatter (recomendado)

```yaml
title: My First Blog Post
date: "2022-01-01"
```

✔ Mayor flexibilidad
✔ Método usado en este enfoque


## 🖥 Mostrar fecha en template

En `post.xhtml`:

```njk
{% include 'includes/header.xhtml' %}
{% if title %}<h1 class="mb-1">{{ title }}</h1>{% endif %}
<p class="m-0">By {{ author }} | Posted on {{ page.date }}</p>
{{ content }}
{% include 'includes/footer.xhtml' %}
```


# ⚠ Problema de zona horaria

11ty:

* Guarda fecha en UTC
* A medianoche
* Puede mostrar el día anterior según timezone

Ejemplo:

* Fecha definida → `2022-01-01`
* Se muestra → `December 31`

Es un problema documentado en la guía oficial de Eleventy.


# 🧠 Solución propuesta: usar Directory Data + Luxon

11ty incluye internamente la librería:

Luxon

Se puede usar en `posts.11tydata.js` para:

* Tomar `page.date`
* Ajustar timezone
* Generar string formateado estable


# 🔧 Usar `eleventyComputed`

## 📌 Qué es

`eleventyComputed`:

* Se ejecuta al final del Data Cascade
* Tiene acceso a todos los datos
* Permite crear nuevas variables dinámicamente

Debe declararse dentro del objeto exportado:

```js
module.exports = {
  layout: "layouts/post.xhtml",
  tags: ["post"],
  author: "Bryan Robinson",

  eleventyComputed: {
    // funciones aquí
  }
}
```
## 🧩 Cómo funciona

* Cada propiedad puede ser una función.
* Recibe el objeto completo de datos.
* Retorna el valor final que se inyecta en la página.
* Se puede desestructurar `{ page }` para acceder a `page.date`.


# 🎯 Objetivo

Crear una nueva variable, por ejemplo:

```
dateString
```

Que:

* Use `page.date`
* Ajuste zona horaria
* Devuelva formato consistente
* Evite el “off by one day”
