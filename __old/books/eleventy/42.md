## 11ty — Fechas formateadas, Next/Previous y listado de posts (Resumen Ultra Compacto, fiel al texto)

---

# 📅 Fecha consistente con Luxon + `eleventyComputed`

En `posts.11tydata.js`:

```js
const { DateTime } = require("luxon")

module.exports = {
  layout: "layouts/post.xhtml",
  tags: ["post"],
  author: "Bryan Robinson",

  eleventyComputed: {
    dateString: ({ page }) =>
      DateTime
        .fromJSDate(page.date, { zone: "utc" })
        .toLocaleString(DateTime.DATE_FULL)
  }
}
```

### 🔎 Qué hace

* Toma `page.date`
* Fuerza zona `utc`
* Genera string consistente
* Evita el error de desfase por timezone

En el layout usar:

```njk
<p class="m-0">
  By {{ author }} | Posted on {{ dateString }}
</p>
```

✔ Ahora la fecha es estable y predecible.

# 🔁 Mostrar Next / Previous Post

11ty provee filtros sobre collections.

En `post.xhtml`, agregar al final:

```njk
{% assign nextPost = collections.post | getNextCollectionItem %}
{% assign previousPost = collections.post | getPreviousCollectionItem %}

{% if nextPost %}
  <div class="mt-4">
    <h3>Next Post</h3>
    <h4>
      <a href="{{ nextPost.url }}">
        {{ nextPost.data.title }}
      </a>
    </h4>
  </div>
{% endif %}

{% if previousPost %}
  <div class="mt-4">
    <h3>Previous Post</h3>
    <h4>
      <a href="{{ previousPost.url }}">
        {{ previousPost.data.title }}
      </a>
    </h4>
  </div>
{% endif %}
```

### 📌 Resultado

* Muestra siguiente y anterior si existen.
* No requiere JS adicional.
* Usa `collections.post`.

# 📚 Crear página de listado `/posts/`

Editar `posts.xhtml`:

```njk
---
title: "All Posts"
layout: "layouts/base.xhtml"
---

{% for post in collections.post %}
  <article>
    <h2 class="mb-1">
      <a href="{{ post.url }}">
        {{ post.data.title }}
      </a>
    </h2>

    <p>
      By {{ post.data.author }} |
      Posted on {{ post.data.dateString }}
    </p>
  </article>
{% endfor %}
```

### 🔎 Qué ocurre

* `collections.post` contiene todos los posts con tag `"post"`.
* Se itera con `for`.
* Se accede a datos vía `post.data`.
* Se usa `post.url` para el enlace.
