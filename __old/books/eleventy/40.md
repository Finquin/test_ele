## 11ty — Tags, Directory Data y Layout personalizado (Resumen Ultra Compacto, fiel al texto)


## ⚠ WARNING: `tags`

* En 11ty, `tags` está diseñado para **collections**.
* No usarlo como sistema general de categorías.
* Puede generar efectos secundarios.
* Las categorías dinámicas se verán más adelante.


## 📂 Directory Data File (limpiar repetición)

Crear en:

```bash
src/posts/posts.11tydata.js
```

Contenido:

```js
module.exports = {
  layout: "layouts/base.html",
  tags: ["post"],
  author: "Bryan Robinson"
}
```

📌 Claves:

* El sufijo `.11tydata.js` es obligatorio.
* Aplica datos a todos los archivos del directorio.
* Permite lógica dinámica (por eso se usa JS y no JSON).
* Ahora se pueden eliminar `layout` y `tags` del frontmatter individual.

Resultado:

* Menos repetición.
* Autor disponible globalmente.
* Posts agregados automáticamente a `collections.post`.



# 🧩 Crear layout personalizado para posts

## 🎯 Problema

Usar solo `base.xhtml` implicaría:

* Múltiples condicionales
* Código difícil de mantener
* Mezcla de responsabilidades

Solución: crear layout específico para posts.



## 🏗 Crear nuevo layout

En:

```bash
src/_templates/layouts/
```

Crear:

```bash
post.xhtml
```



# 🔁 Refactorizar `base.xhtml` usando includes

Para reutilizar estructura HTML:

Crear en:

```bash
src/_templates/includes/
```

### 📄 `header.xhtml`

Contiene:

* `<!DOCTYPE>`
* `<html>`
* `<head>`
* `<body>`
* `<nav>`
* Apertura del contenedor principal

### 📄 `footer.xhtml`

Contiene:

* Cierre del contenedor
* `</body>`
* `</html>`



## 🔄 Actualizar `base.xhtml`

Reemplazar HTML repetido por includes:

"```njk
{% include 'includes/header.html' %}
{% if title %}<h1>{{ title }}</h1>{% endif %}
{{ content }}
{% include 'includes/footer.html' %}
```"

📌 Ahora `base` es modular y reutilizable.


# 📝 Layout específico: `post.xhtml`

Agregar ajustes propios de un post:

```njk
{% include 'includes/header.xhtml' %}

{% if title %}
<h1 class="mb-1">{{ title }}</h1>
{% endif %}

{% if author %}
<p class="m-0">
  By {{ author }} | Posted on {{ dateString }}
</p>
{% endif %}

{{ content }}

{% include 'includes/footer.xhtml' %}
```

### Cambios clave:

* Byline (autor + fecha)
* Ajuste visual (márgenes)
* Diseño más apropiado para artículos



## 🔄 Actualizar Directory Data

Cambiar layout en `posts.11tydata.js`:

```js
module.exports = {
  layout: "layouts/post.xhtml",
  tags: ["post"],
  author: "Bryan Robinson"
}
```



# 🎯 Resultado Final

* `base.xhtml` → layout general
* `post.xhtml` → layout específico para blog
* Includes → estructura HTML reutilizable
* Directory data → menos repetición
* `collections.post` → agrupación automática
