## 11ty — Collections y Directory Data (Resumen Ultra Compacto, fiel al texto)

---

## 📦 ¿Qué es una Collection?

Una **collection** es un agrupamiento especial de contenido en 11ty.

Se crea cuando varias páginas comparten:

* Un array `tags` en el **data cascade**
* O una definición programática en `eleventy.config.js`

📌 Resultado:

* El grupo puede iterarse desde cualquier template vía `collections`
* Puede manipularse con la **Collection API**

Uso típico:

* Blog posts
* Imágenes
* Episodios de podcast
* Cualquier contenido relacionado

---

## 📝 Crear colección con carpeta + Markdown

### 1️⃣ Crear estructura

```
src/
└─ posts/
```

Dentro de `posts/`, crear:

* `my-first-blog-post.md`
* `my-second-blog-post.md`

📌 El nombre del archivo será la URL del post.

---

### 2️⃣ Agregar frontmatter

Ejemplo:

```
---
title: My First Blog Post
layout: "layouts/base.xhtml"
tags:
  - "post"
---

## This is a headline for a blog post
This is a paragraph for a blog post.
```

Esto:

* Genera una página individual
* La agrega a `collections.post`
* El nombre de la colección proviene del string `"post"`

⚠ Evitar `<h1>` en el contenido si el layout ya lo incluye (SEO + accesibilidad).

---

## ⚠ Advertencia sobre `tags`

En 11ty, `tags` está orientado a **collections**.

No usarlo como:

* Sistema de categorías
* Clasificación general de blog

Puede generar efectos secundarios.

---

## 📂 Crear Directory Data File

Para evitar repetir `layout` y `tags` en cada post:

Crear en:

```id="iq8yq0"
src/posts/posts.11tydata.js
```

Contenido:

```js id="0kgn8m"
module.exports = {
    layout: "layouts/base.xhtml",
    tags: ["post"],
    author: "Bryan Robinson"
}
```

📌 Claves:

* El nombre `*.11tydata.js` es obligatorio.
* Aplica datos a todos los archivos del directorio.
* Permite usar lógica JS si se necesita dinámicamente.

---

## 🎯 Resultado

Ahora cada post:

* Hereda automáticamente:

  * `layout`
  * `tags`
  * `author`
* Puede sobrescribir datos en su frontmatter.
* Tiene menos repetición.
* Está correctamente agregado a una collection.
