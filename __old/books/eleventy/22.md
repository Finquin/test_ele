## 11ty — Layout base y separación de templates (Resumen Ultra Compacto, fiel al texto)

---

## 📁 Estructura dentro de `src/_templates/`

Todos los templates se almacenarán en:

```
src/_templates/
```

Dentro de esa carpeta crear:

```
src/_templates/
│
├─ includes/
└─ layouts/
```

📌 Esta separación **no es obligatoria**, pero mejora claridad y organización.

---

## 🏗 Crear layout principal

En:

```
src/_templates/layouts/
```

Crear:

```
base.xhtml
```

Este será el **layout principal del sitio**.

---

## 🔁 Qué mover al layout

Desde `index.xhtml`, trasladar a `base.xhtml`:

* `<!DOCTYPE html>`
* `<html>`
* `<head>` completo (meta, title, link CSS)
* `<header>` (logo SVG + navegación)
* `<footer>`
* Cierre de `</body>` y `</html>`

📌 En `index.xhtml` debe quedar **solo el contenido específico de la página**.

---

## 🧩 Insertar contenido dinámico

En `base.xhtml`, entre el header y el footer, agregar:

```html
{{ content }}
```

Ese tag inserta el contenido único de cada página dentro del layout.

---

## 🧱 Estructura final de `base.xhtml`

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta http-equiv="X-UA-Compatible" content="IE=edge">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My amazing title</title>
    <link rel="stylesheet" href="/assets/css/style.css">
</head>
<body>
    <header class="site-header">
        <!-- Logo SVG -->
        <nav>
            <ul>
                <li class="active"><a href="/">Home</a></li>
                <li><a href="/about">About</a></li>
            </ul>
        </nav>
    </header>

    {{ content }}

    <footer class="footer">
        <p>Copyright 2022</p>
    </footer>
</body>
</html>
```

---

## 🎯 Idea clave

* `base.xhtml` contiene la estructura HTML global.
* Las páginas contienen solo contenido específico.
* `{{ content }}` actúa como punto de inyección.
* Se establece una arquitectura reutilizable y mantenible.
