## 11ty — Configuración básica (Resumen Ultra Compacto)

### 📁 Archivo de configuración

* Crear `eleventy.config.js` en la raíz del proyecto.
* Es un archivo **Node.js**.
* Exporta una función usando `module.exports`.

Estructura base:

```js
// Requerir plugins si es necesario
const plugin = require('some-eleventy-plugin-package')

module.exports = function(eleventyConfig) {
  // Configuración y métodos de 11ty
  return {
    // Opciones
  }
}
```

---

### 📦 Copiar assets (CSS, JS, imágenes)

Por defecto, 11ty **no procesa ni copia archivos estáticos** automáticamente.

Para copiar la carpeta `assets` al build:

```js
module.exports = function(eleventyConfig) {
  eleventyConfig.addPassthroughCopy("assets");
}
```

🔎 `addPassthroughCopy()`:

* Recibe un directorio existente.
* Lo copia a `_site/` manteniendo la estructura.
* Permite que el CSS (ej: `/assets/style.css`) funcione correctamente.

---

### 🔄 Reiniciar servidor

Después de modificar `eleventy.config.js`:

1. Detener servidor → `Ctrl + C`
2. Ejecutar nuevamente:

   ```bash
   npm run dev
   ```

El servidor debe reiniciarse para aplicar cambios.

### 🧩 Mejora estructural recomendada

Por defecto, 11ty usa la raíz del proyecto.

Buenas prácticas:

* Mover archivos principales a un subdirectorio como `src/`.
* Mejora organización.
* Reduce desorden en proyectos medianos/grandes.
